# 🤖 وكيل سطح المكتب — CEM Desktop Agent

روبوت ذكاء اصطناعي يرى شاشتك ويتحكم بالماوس والكيبورد تلقائياً.

## ما يستطيع فعله

- فتح أي برنامج أو موقع
- إدخال النقاط على موقع وزارة التربية الوطنية
- تعبئة أي نموذج إلكتروني
- البحث والتنقل بين الصفحات
- نسخ ولصق البيانات
- أي شيء تفعله أنت — لكن أسرع

## إعداد سريع (Windows)

```bash
# 1. تأكد من تثبيت Python 3.10+
python --version

# 2. ثبّت المكتبات
cd desktop_agent
pip install -r requirements.txt

# 3. أنشئ ملف .env
copy .env.example .env
# عدّل .env وأضف مفتاح GROQ_API_KEY

# 4. شغّل الوكيل
python agent.py
```

## الحصول على مفتاح Groq (مجاني)

1. افتح [console.groq.com](https://console.groq.com)
2. سجّل حساباً مجانياً
3. اضغط **Create API Key**
4. انسخ المفتاح وألصقه في ملف `.env`

## طرق الاستخدام

```bash
# وضع تفاعلي (يطلب منك المهمة)
python agent.py

# مهمة مباشرة
python agent.py --task "افتح Chrome وانتقل لموقع وزارة التربية"

# إدخال النقاط من قاعدة بيانات التطبيق تلقائياً
python agent.py --grades

# اختبار بدون تنفيذ فعلي (يعرض ما سيفعله)
python agent.py --task "..." --dry-run
```

## مثال — إدخال نقاط الوزارة

```bash
python agent.py --task "
ادخل على موقع وزارة التربية الوطنية الجزائرية.
سجّل الدخول بالمعرّف: 123456 والرمز: mypassword
انتقل لصفحة إدخال نقاط الفصل الأول.
أدخل النقاط التالية:
  - بن علي أحمد: 14.5
  - بوعزيز فاطمة: 16
  - كريمي يوسف: 11.25
احفظ وتأكد من النجاح.
"
```

## الأمان والتوقف

- **توقف فوري**: حرّك الماوس لـ**الزاوية العلوية اليسرى** من الشاشة
- **إيقاف مؤقت**: اضغط `Ctrl+C` مرة واحدة (اضغط مرة ثانية للاستمرار)
- **إيقاف كامل**: اضغط `Ctrl+C` مرتين متتاليتين

## السجلات

كل جلسة تُحفظ في مجلد `logs/` بصيغة JSONL تتضمن كل خطوة.

## ملاحظات

- الوكيل يحتاج صلاحيات الشاشة (Screen Recording على Mac)
- على Windows لا توجد صلاحيات إضافية مطلوبة
- أفضل نتائج مع شاشة 1920×1080
